                   TRANSPORTATION FEE CALCULATION
═══════════════════════════════════════════════════════════════════════════════

Example from Screenshot:

Equipment Location: Pinamalayan (🟢 Green Marker)
Delivery Location:  Socorro     (🔴 Red Marker)
Distance:           6.72 km

Owner's Fee Settings:
┌────────────────────────────────┐
│ Free Distance:    5.00 km      │
│ Base Fee:         ₱100.00      │
│ Per Km Rate:      ₱15.00/km    │
└────────────────────────────────┘

Calculation:
┌──────────────────────────────────────────────────┐
│ Step 1: Calculate billable distance              │
│ Billable = Total - Free                          │
│ Billable = 6.72 - 5.00 = 1.72 km                 │
│                                                   │
│ Step 2: Calculate per-km charge                  │
│ Per Km = Billable × Rate                         │
│ Per Km = 1.72 × ₱15 = ₱25.80                     │
│                                                   │
│ Step 3: Add base fee                             │
│ Total = Base + Per Km                            │
│ Total = ₱100 + ₱25.80 = ₱125.80                  │
│                                                   │
│ Result: ₱125.77 (after rounding)                 │
└──────────────────────────────────────────────────┘

If within free distance (≤5 km): ₱0
If beyond free distance (>5 km): Base + (Extra × Rate)
