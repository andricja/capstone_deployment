HOW TO USE
═══════════════════════════════════════════════════════════════════════════

1. Login as admin
2. Go to Admin → Archive (in sidebar)
3. Select a tab: Owners, Equipment, Rentals, or Payments
4. You'll see all archived items in a table

TO RESTORE ITEMS:
- Click checkbox next to item(s)
- Click "Restore Selected" button
- Items will be restored to original state

TO DELETE PERMANENTLY:
- Click checkbox next to item(s)
- Click "Delete Permanently" button
- Confirm the warning (cannot be undone!)
- Items are permanently deleted from database

SINGLE ITEM ACTIONS:
- Click restore icon (↻) to restore one item
- Click trash icon (🗑) to delete one item permanently

API ENDPOINTS ADDED
═══════════════════════════════════════════════════════════════════════════

GET /api/admin/archived/owners          - Get all archived owners
GET /api/admin/archived/equipment       - Get all archived equipment
GET /api/admin/archived/rentals         - Get all archived rentals
GET /api/admin/archived/payments        - Get all archived payments

PATCH /api/admin/owners/{id}/restore    - Restore single owner
PATCH /api/admin/equipment/{id}/restore - Restore single equipment
PATCH /api/admin/rentals/{id}/restore   - Restore single rental
PATCH /api/admin/payments/{id}/restore  - Restore single payment

POST /api/admin/archived/owners/bulk-restore     - Bulk restore owners
POST /api/admin/archived/equipment/bulk-restore  - Bulk restore equipment
POST /api/admin/archived/rentals/bulk-restore    - Bulk restore rentals
POST /api/admin/archived/payments/bulk-restore   - Bulk restore payments

POST /api/admin/archived/owners/bulk-delete      - Bulk delete owners
POST /api/admin/archived/equipment/bulk-delete   - Bulk delete equipment
POST /api/admin/archived/rentals/bulk-delete     - Bulk delete rentals
POST /api/admin/archived/payments/bulk-delete    - Bulk delete payments

DELETE /api/admin/archived/owners/{id}     - Delete single owner permanently
DELETE /api/admin/archived/equipment/{id}  - Delete single equipment permanently
DELETE /api/admin/archived/rentals/{id}    - Delete single rental permanently
DELETE /api/admin/archived/payments/{id}   - Delete single payment permanently
