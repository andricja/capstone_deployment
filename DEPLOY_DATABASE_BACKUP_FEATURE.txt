=============================================================================
WHAT THIS FEATURE DOES
=============================================================================

BEFORE (Old Method):
1. SSH into server
2. cd to backend directory
3. Run ./backup.sh script
4. Find backup file on server
5. SCP download to local machine

AFTER (New Method):
1. Click "Export Database Backup" button
2. SQL file downloads automatically

Admin Settings Now Has:
├── Profile
├── Password
├── Archive
├── Accounts
├── Audit Trail
├── Email Settings
└── Database Backup ← NEW TAB
    ├── Export Button (one-click download)
    ├── Database Statistics (name, tables, rows, size)
    ├── Tables List (detailed per-table stats)
    └── Recent Backups (last 5 exports)

=============================================================================
TROUBLESHOOTING
=============================================================================

Issue: "Route not found" error
Fix: Run php artisan route:clear

Issue: "Permission denied" creating backup
Fix: chmod 755 storage/app/backups

Issue: Export button doesn't work
Fix: Check browser console (F12) for errors

Issue: Downloaded file is empty
Fix: Check mysqldump is available: which mysqldump

Issue: Button stuck on "Exporting..."
Fix: Check server logs: tail -f storage/logs/laravel.log
