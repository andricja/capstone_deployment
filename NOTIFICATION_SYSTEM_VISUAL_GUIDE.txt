═══════════════════════════════════════════════════════════════════════════
  LOCALSTORAGE: How It Works Behind the Scenes
═══════════════════════════════════════════════════════════════════════════

Browser LocalStorage:
{
  "viewed_owner_rentals": [45, 46, 47]  ← IDs of clicked items
}

When page loads:
  → Read from localStorage
  → Item ID 45? IN ARRAY → Don't show red dot
  → Item ID 46? IN ARRAY → Don't show red dot
  → Item ID 47? IN ARRAY → Don't show red dot
  → Item ID 48? NOT IN ARRAY → Show red dot 🔴
  → Item ID 49? NOT IN ARRAY → Show red dot 🔴

When user clicks item 48:
  → Add 48 to array: [45, 46, 47, 48]
  → Save to localStorage
  → Re-render: red dot disappears

When user refreshes page (F5):
  → Read from localStorage: [45, 46, 47, 48]
  → Item 48 still IN ARRAY
  → Red dot stays gone ✓

═══════════════════════════════════════════════════════════════════════════
  COMPONENT HIERARCHY
═══════════════════════════════════════════════════════════════════════════

React Component Tree:

AdminOwners
├── useViewedItems('viewed_admin_owners')  ← Hook tracks viewed IDs
│   └── localStorage: [12, 34, 56]
│
├── Tab: "Equipment Owners"
│   └── <TabBadge count={2} />  ← Shows [2]
│
└── Owner Cards (loop)
    ├── Owner #12
    │   └── <RowBadge isNew={false} />  ← No dot (ID in storage)
    ├── Owner #45
    │   └── <RowBadge isNew={true} />   ← 🔴 Red dot (ID NOT in storage)
    └── Owner #67
        └── <RowBadge isNew={true} />   ← 🔴 Red dot (ID NOT in storage)

═══════════════════════════════════════════════════════════════════════════
  DATA FLOW: Click to Dismiss
═══════════════════════════════════════════════════════════════════════════

1. User clicks Owner #45 card
   └─> onClick={() => ownerViewed.markAsViewed(45)}

2. markAsViewed(45) executes
   └─> viewedIds: [12, 34, 56] + 45
   └─> viewedIds: [12, 34, 56, 45]

3. Save to localStorage
   └─> localStorage.setItem('viewed_admin_owners', '[12,34,56,45]')

4. React re-renders
   └─> ownerViewed.isNew(45) returns FALSE
   └─> <RowBadge isNew={false} /> renders nothing

5. Red dot disappears ✓

6. Tab badge recalculates
   └─> newOwnersCount: 3 → 2
   └─> <TabBadge count={2} />
