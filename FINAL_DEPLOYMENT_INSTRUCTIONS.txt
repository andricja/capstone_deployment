TROUBLESHOOTING
=============================================================================

PROBLEM: Red dots not showing
SOLUTION:
  1. Clear browser cache (Ctrl+Shift+Del)
  2. Hard refresh (Ctrl+Shift+R)
  3. Check console (F12) for errors
  4. Verify deployment: check https://ferms.net/assets/ folder

PROBLEM: Red dots not disappearing when clicked
SOLUTION:
  1. Check if localStorage is enabled
  2. Look for JavaScript errors in console
  3. Verify the item status is correct (e.g., 'forwarded', 'pending')

PROBLEM: Red dots come back after refresh
SOLUTION:
  1. Check localStorage in DevTools
  2. Look for the storage keys
  3. Verify IDs are being saved
  4. Clear localStorage and try again

PROBLEM: Build file 404 error
SOLUTION:
  1. Re-deploy entire dist/ folder
  2. The file hash (index-CAfQ30qb.js) might change
  3. Make sure index.html is deployed too
